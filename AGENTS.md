Projektregler

## Formål
Projektet er et website om bagning for begyndere.
                                       Websitet skal implementeres så præcist som muligt ud fra mit færdige Figma-design.

## Teknologi
- Brug semantisk HTML.
- Brug struktureret CSS.
- Simpel vanilla JavaScript må bruges, hvis det er nødvendigt.
- Ingen frameworks.
- Ingen backend.
- Ingen database.
- Ingen login eller brugerprofiler.
- Ingen betalingsløsning.
- Ingen eksterne API'er.

## Figma
- Figma-designet er den visuelle reference.
- Undersøg relevante desktop- og mobilframes før implementering.
- Bevar layout, farver, typografi, billeder, spacing og UI-elementer så tæt på Figma som muligt.
- Gæt ikke på designet, hvis informationen kan findes i Figma.

## Sider
Websitet består af fire sider:
1. Forside
2. Kom i gang
3. Udstyr
4. Første projekt

Navigationen mellem siderne skal fungere.

## Responsivitet
- Websitet skal fungere på både desktop og mobil.
- Brug Figma-designet som reference.
- Layoutet skal tilpasse sig naturligt mellem skærmstørrelser.

## Kode
- Brug genbrugelige CSS-klasser.
- Brug CSS custom properties til farver, typografi og andre værdier, der gentages.
- Brug korrekt heading-hierarki.
- Brug relevante alt-tekster til billeder.
- Hold koden enkel og overskuelig.
